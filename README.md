# Automated Extraction of Company & Job Details from LinkedIn Profiles for Investment Analysis

## 📌 Project Overview
This project automates the extraction of **company details and job listings** from LinkedIn profiles to support **investment analysis and job market insights**.  
Using web scraping and data processing techniques, the system converts unstructured LinkedIn data into structured datasets that can be analyzed for business intelligence, hiring trends, and investment decisions.

The project reduces manual effort, improves accuracy, and enables faster access to actionable insights for investors, analysts, and job seekers.

---

## 🎯 Objectives
- Automate extraction of company and job details from LinkedIn
- Analyze hiring trends to evaluate company growth
- Reduce time-consuming manual data collection
- Store extracted data in structured formats (CSV / Database)
- Ensure ethical and compliant data extraction

---

## 🔍 Key Features

### ✅ Company Details Extraction
- Company Name
- Industry Type
- Employee Strength
- Location
- Funding Status
- Organizational Keywords

### ✅ Job Details Extraction
- Job Title
- Company Name
- Job Location
- Employment Type (Full-time / Internship / Remote)
- Required Skills & Keywords
- Job Posting Date
- Job Description Summary

### ✅ Technical Capabilities
- Automated LinkedIn navigation using **Selenium**
- HTML parsing using **BeautifulSoup**
- Data cleaning and preprocessing
- CSV and MySQL database storage
- GUI-based interaction using **Tkinter**
- Scalable and modular architecture
